# Evolve PyProc

## Outcome

Turn a reproducible product gap into one owned contract without presenting unfinished work as shipped behavior.

## Read first

Read contract reality for gaps, consumer feedback for intake, and experimental freeze before changing public surface.

## Procedure

1. Reproduce the gap against the public contract.
2. Route experimental evidence to one attempt campaign.
3. Use one sequential initiative for repository-wide work.
4. Graduate only after product gates and current documentation ownership are complete.
5. Delete completed plan and attempt directories in the same cycle.

## Verification

Run `npm test` plus the capability gates named by changed-path routing.

## Failure modes

Reject duplicate initiatives, speculative public exports, copied consumer secrets, permanent compatibility layers, and completed plan archives.
