# Automate Browser with PyProc

## Outcome

Observe and act through bounded semantic browser contracts with evidence and explicit risk.

## Read first

Read browser automation for live CDP work. Use the matching Space or actuation reference for other providers.

## Procedure

1. Declare allowed origins, actions, risk, and effect acknowledgement.
2. Open and attach an opaque target.
3. Observe before acting and use returned semantic references.
4. Verify actionability and postconditions within bounded windows.
5. Detach and delete sensitive artifacts when finished.

## Verification

Run browser control, stress, Space, actuation, installed, and browser product gates selected by routing.

## Failure modes

Stop on stale locators, intercepted targets, undeclared destinations, cross-origin escape, unverified effects, or raw browser authority leaks.
