# Verify Browser Experience

## Outcome

Produce replayable evidence that distinguishes verified, rejected, unknown, and review-required claims.

## Read first

Read the APX contract and verification workflow. Read situation or interop details only when needed.

## Procedure

1. State scenario, checkpoint, environment, viewport, and expected claims.
2. Observe semantic and visual evidence through an approved provider.
3. Correlate each action with before, after, and event evidence.
4. Publish a canonical Evidence Pack.
5. Replay without live provider effects and compare stable findings.

## Verification

Run APX, perception, experience verification, golden vector, and installed product gates.

## Failure modes

Reject DOM-only visual claims, missing provenance, incomplete coverage presented as pass, stale packs, and advisory findings promoted to blockers without policy.
